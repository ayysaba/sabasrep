ჩემ შესახებ

გამარჯობა! მე ვარ საბა მჭედლიშვილი, 16 წლის. ახლახან დავიწყე პროგრამირების შესწავლა და ძალიან მაინტერესებს ვებ-ტექნოლოგიები. ამ ეტაპზე აქტიურად ვსწავლობ HTML5-ს, CSS3-სა და JavaScript-ის საფუძვლებს.

ჩემი მიზანია შევქმნა სუფთა, სემანტიკური და მომხმარებლისთვის მოსახერხებელი ვებ-გვერდები.

„ყველა გამოცდილი დეველოპერი ოდესღაც დამწყები იყო.“

უნარები და ტექნოლოგიები

  • HTML5 - სემანტიკური მარკირება 85% სემანტიკური ელემენტები, ფორმები, ცხრილები და ხელმისაწვდომობა (A11y).
  • CSS3 - სტილები და დიზაინი 70% Flexbox, Grid, მედია მოთხოვნები (Media Queries) და რესფონსიული განლაგება.
  • JavaScript - საბაზისო ინტერაქციები 50% DOM-თან მუშაობა, მოვლენების დამუშავება (Event Listeners) და ლოგიკა.
  • Git & GitHub - ვერსიების კონტროლი 45% კოდის ატვირთვა, რეპოზიტორიების მართვა და GitHub Pages.
დამატებითი დეტალები სასწავლო პროგრამის შესახებ
  • Semantic Tags: <header>, <nav>, <main>, <section>, <article>, <footer>
  • CSS Variables, Flexbox, Media Queries (Mobile First & Desktop)
  • ფორმის ვალიდაციები და ტიპები

პროექტი 1: პირადი სავიზიტო გვერდი

ტექნოლოგიები: HTML5, CSS3
